# PROJECT DESCRIPTION

```Shopping List API is a REST API built with Node.js and TypeScript that allows users to manage items they want to buy. Users can add, view, update, and delete shopping list items. Each item contains information such as its name, quantity, and purchased status. The application stores items in memory using an array and allows users to interact with the API through HTTP requests using tools such as Postman. The project demonstrates core backend concepts such as REST APIs, HTTP methods, routing, validation, error handling, TypeScript types, and CRUD operations.```
